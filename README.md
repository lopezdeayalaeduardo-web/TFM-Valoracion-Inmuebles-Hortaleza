Repositorio complementario del Trabajo de Fin de Máster

## Descripción

El proyecto desarrolla un sistema de valoración automatizada de viviendas mediante Machine Learning, incorporando variables inmobiliarias y geoespaciales para el distrito de Hortaleza (Madrid). Se comparan distintos modelos predictivos, se analiza la aportación de la información espacial, se estudia la interpretabilidad mediante SHAP y se integra el modelo final en una aplicación web desarrollada con Streamlit y Folium.
